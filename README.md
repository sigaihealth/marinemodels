# Pioneer storm scores

The [live scorecard](REPORT.md) tracks six-hour salinity forecasts at the Coastal Pioneer Array. Each refresh compares the original, frozen November tide-and-current model with persistence on the same measurements. November and the next three qualifying storms have separate rows. The branch history preserves earlier observations and provisional scores. [Methods and source code](https://github.com/sigaihealth/marinemodels/tree/main/world-model/pioneer-fixed-confirmation)
