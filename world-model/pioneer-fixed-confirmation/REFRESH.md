# Refresh the prospective Pioneer storm inputs

Run `python refresh_inputs.py --world-model /path/to/marinemodels/world-model --out /path/to/inputs`. The optional `--as-of 2026-11-26T02:00:00Z` caps the measurement time for a retrospective read. The default is the most recent completed UTC hour. The command uses Python's standard library, public data and the repository's original hourly preprocessing. For repeat runs use a persistent `--cache` directory (default `inputs/.cache`). Write to a single output directory with one writer at a time. Source errors fail the command and retain the previous snapshot. Read the final provenance file and verify its CSV hashes before scoring.

* CTD and currents come from Pioneer Central, nominal 7 m instruments CP10CNSM-RID27-03-CTDBPC000 and CP10CNSM-RID26-04-VELPTA000. The previous study's QARTOD, deployment, freshness and paired vector checks apply. The refresh records the current asset CSV and all source query hashes. Recent and open-ended ERDDAP ranges are requested again. Sealed ranges older than 21 days are rechecked weekly. Receipt times for historical records are unavailable. [OOI Pioneer Central](https://oceanobservatories.org/site/cp10cnsm/)
* Hourly tide predictions come from Duck, station 8651370, in metres relative to MLLW and in UTC. Predictions extend through at least the six-hour forecast horizon. [NOAA CO-OPS](https://tidesandcurrents.noaa.gov/stationhome.html?id=8651370)
* Significant wave height comes from the full-precision half-hourly CDIP Oregon Inlet record (192p1, WMO 44095). The refresher reconciles the station's current and archived deployments and uses the end of the averaging interval and primary QC flag 1. The latest observed physical sample, latest passing sample, and per-source checksums are in `refresh_provenance.json`. Hourly selection, the 3 m two-hour threshold, declustering, and 12-hour pre/24-hour post windows come from the frozen study. [CDIP station archive](https://thredds.cdip.ucsd.edu/thredds/catalog/cdip/archive/192p1/catalog.html)
* A storm's onset supplies its tracking key. Its peak-based study ID may change while waves arrive. Local maturity requires observed wave coverage to at least 72 hours after the last qualifying run, enough time for the full issue window and six-hour outcomes, and sufficient local sampling. A bin with fewer than two passing half-hourly records can introduce ambiguity unless fully sampled calm hours flank it. Critical gaps in the preceding cohort history make the subsequent event order tentative (`sequence_certain=0`). The interval begins before the known November event to cover onset and declustering. A temporary source outage cannot create observed calm hours. A single most-recent high hour awaiting confirmation is reported in provenance when present.
* `events.csv` status describes the wave window. The scorer must separately check temperature, salinity, tide and current coverage and every matched forecast/verification hour. `ctd_through` and `currents_through` give last usable issue hours. `waves_through` is the last observed hour bin. `tides_through` is the last predicted tide hour. Full source reports and the SHA-256 digests of the five CSVs accompany the snapshot.

Run `PIONEER_WORLD_MODEL=/path/to/marinemodels/world-model python test_refresh.py` to exercise the monitoring boundary cases.
