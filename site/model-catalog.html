Ocean physics forecasting

Ingest dated ocean analyses and model-specific atmospheric forcing. Use GLONET as the default baseline for global forecasts and retain persistence as a low-cost reference.

Browse 74 datasets, models and services for this task in the source atlas

Explore an archived forecast

How to compare

Match initialization times, lead, variable, depth and wet-cell mask. Use OceanBench for the common global track. Score a separate native-resolution, sub-daily track for eddies and currents where observations resolve them.

OceanBench protocols and code
5 records
GLONETGenerate short-range global ocean physics forecasts.
Input
Two days of initial physical ocean fields. The released workflow retrieves Copernicus Marine initialization and regrids it. The paper trained on GLORYS12.
Output
Ten daily global maps of sea surface height and temperature, salinity and horizontal currents on a 1/4° output grid with 21 depth levels.
Access type
Public weights
Availability
Mercator publishes three depth-specific TorchScript weight files, normalization statistics and inference code. Copernicus Marine credentials are required by its data-fetching workflow.
License scope
EUPL-1.2 for code. CC BY 4.0 for weights and associated statistics.
Compute
The official inference card requires an NVIDIA GPU and reports a ten-day forecast in seconds. Training used multi-GPU pipeline parallelism. Download, regridding and output I/O add elapsed time. L40S performance has not been measured here.
Evaluation
Use its OceanBench GLO12-initialized 2024 challenger scores against GLO12 and persistence on the same track and grid. Extract wet grid cells around Pioneer and compare against matched station temperature, salinity and currents.
Notes
The card distinguishes its 1/4° output grid from an author-described 1/12° effective resolution. Use the actual output grid for coastal collocation.

FuXi-OceanForecast sub-daily global ocean physics and storm responses.
Input
Four historical six-hour states with HYCOM ocean fields and five near-surface atmospheric variables. ERA5 supplied atmospheric training inputs. The rollout needs no future atmospheric forecast.
Output
Six-hourly 1/12° temperature, salinity and horizontal currents on 26 levels to 1,500 m, plus sea surface height, through ten days.
Access type
Weights unverified
Availability
The authors’ DOI archive contains a README, requirements and two inference scripts. The inference script expects an external ONNX file. The author GitHub tree also provides scripts. A publicly downloadable author-trained checkpoint was not verified.
License scope
CC BY 4.0 on the cited Zenodo deposit. A license for the missing trained weights is unverified.
Compute
Authors report 72 seconds for a ten-day global forecast on one H100. This is inference. Local peak memory and L40S runtime are unverified.
Evaluation
The paper tested 2022 forecasts against HYCOM, OceanMAPS, FOAM and WenHai with satellite and in-situ reference data, including profiles and currents. The paper averaged FuXi-Ocean output to daily means for daily comparisons. These are separate from Mercator’s 2024 OceanBench scores.
Notes
Author code: https://github.com/huangqiusheng/FuXi-Ocean. The OneScience-Group engineering reproduction describes synthetic training tiles and disclaims original weights (https://huggingface.co/OneScience-Group/FuXi-Ocean).

WenHaiForecast the eddying upper ocean with physically calculated air–sea fluxes and a Swin Transformer.
Input
Five initial ocean variables, plus eight surface atmospheric variables to calculate fluxes. Training used GLORYS and ERA5. The operational-style comparison used GLO12 initialization and IFS atmospheric forecasts.
Output
Daily 1/12° sea surface height and temperature, salinity and horizontal currents on 23 vertical levels down to about 644 m.
Access type
Public weights
Availability
The author repository links the WenHai.onnx weights, example inputs, masks and normalization arrays in Google Drive. The public folder lists the weight file.
License scope
The v1.0 archived GitHub source release is marked CC BY 4.0 (https://doi.org/10.5281/zenodo.14881628). The ONNX file is delivered separately. Its license was not verified.
Compute
The paper describes a high-resolution training stage exceeding 80 GB of GPU memory before distributing layers across devices. The author supplies ONNX inference code. Peak inference memory and L40S latency are unverified.
Evaluation
The authors compared with GLO12v4 under matched initialization and forcing in April–November 2024. OceanBench hosts a common 2024 comparison with XiHe, GLONET and persistence. Score station errors by depth and forecast lead.
Notes
The released GLORYS mask differs from the GLO12 mask. Check grid and wet-cell consistency before matching Pioneer observations.

XiHePredict global eddy-resolving ocean physics at fixed leads.
Input
Initial ocean state and 10 m zonal/meridional wind. The original work trained on GLORYS12 and ERA5. The OceanBench challenger used GLO12/IFS.
Output
Global 1/12° temperature, salinity and horizontal currents on 23 levels down to about 644 m, with sea surface height and surface temperature. The released ONNX collection covers lead days one to ten.
Access type
Public weights
Availability
The author repository links pretrained upper/deeper ONNX files for each forecast lead via Google Drive and Baidu mirrors.
License scope
No explicit repository or model-weight reuse license was verified. The arXiv paper’s distribution terms apply to the manuscript.
Compute
The revised paper reports 0.35 s on one GPU for a day-ten prediction. The release supplies lead-specific models. This timing does not establish end-to-end latency for all ten leads, input preparation or local deployment.
Evaluation
The paper uses 2019–2020 satellite/in-situ verification and the IV-TT Class 4 framework. Use the separate OceanBench 2024 run for a like-for-like comparison with GLONET and WenHai.
Notes
Archive the chosen lead, depth partition and exact checkpoint before attributing a forecast to XiHe.

OceanBench (Mercator Ocean International)Evaluate global ocean physics forecasts using a common verification protocol.
Input
Ten-day forecasts initialized on all 52 Wednesdays of 2024. The framework accepts 1/12°, 1/4° and 1° grids and documents the variable, depth and coordinate conventions.
Output
Scores by lead, variable and depth, matched-observation counts, gridded scores and physical diagnostics.
Access type
Benchmark
Availability
Public evaluation code, methods and scores. OceanBench provides no prediction weights of its own.
License scope
EUPL-1.2 for the evaluation project. Reference and challenger datasets carry their providers’ terms.
Compute
Scores can be read from the hosted leaderboard. Re-scoring uses the Python package and reference data. Copernicus Marine sign-in is required for 1/12° evaluations. A forecast-model GPU training budget does not apply.

Check the roster (https://oceanbench.edito.eu/challengers/) and verification definitions (https://oceanbench.edito.eu/evaluation-methods/) for each comparison. Perform separate station-scale validation at Pioneer.

Waves

Combine gridded wave state and weather forcing to forecast sea state. Match a station’s exposure and the model’s offshore grid before using a buoy for validation.

Browse 29 datasets, models and services for this task in the source atlas

How to compare

Hold out whole storms and stations. Score significant wave height in meters, period in seconds and direction using circular error. Match mean, peak and swell definitions before comparing.

NOAA buoy measurement definitions
1 record
Aurora 0.25° WaveForecast global ocean surface waves and atmospheric conditions.
Input
Two six-hourly global states of HRES T0 weather and HRES-WAM wave analysis, 13 atmospheric pressure levels and static fields including the wave mask. Required channels and initialization are specified by Microsoft.
Output
Six-hourly wave fields on a 1/4° grid, including significant wave height, mean direction, periods, wind waves and swell partitions. The paper evaluated horizons to ten days.
Access type
Public weights
Availability
Microsoft publishes aurora-0.25-wave.ckpt and wave static data. Its documentation includes an inference example. Historical HRES T0 and HRES-WAM archive access must be checked separately.
License scope
MIT for the published model repository and Microsoft’s Aurora implementation. ECMWF input datasets are governed by separate terms.
Compute
The published wave checkpoint is 5.04 GB on disk. The paper reports 32 A100s for foundation-model pretraining. Weight size is only one component of inference memory. Wave inference on this L40S has not been timed.
Evaluation
The Nature study compares against ECMWF HRES-WAM. For Pioneer, collocate significant wave height in metres with quality-controlled OOI or NDBC buoy observations and compare errors to persistence or archived wave guidance at identical valid times. Evaluate directions using circular error.
Notes
This is the wave-specific checkpoint, distinct from the atmospheric Aurora checkpoints. Input contract: https://microsoft.github.io/aurora/models.html. Example: https://microsoft.github.io/aurora/example_wave.html.

Biogeochemistry

Forecast chemical or biological concentrations from gridded history and environmental drivers. Surface chlorophyll, dissolved oxygen, nutrients and carbon each need their own observations and units.

Browse 28 datasets, models and services for this task in the source atlas

How to compare

Match analyte, depth, basin, sampling interval and forecast lead. Compare against seasonal climatology and persistence on years excluded from fitting. Report errors by season and sampling coverage.

2 records
Mercator seasonal surface chlorophyll-a U-Net (Martinez Balbontin et al.)Estimate near-global surface chlorophyll-a from physical drivers and produce seasonal forecasts.
Input
Mixed-layer depth, sea surface height, sea surface salinity and temperature. Training paired GLORYS12 with GlobColour observations. Seasonal forecasts use bias-adjusted ECMWF SEAS5 predictors.
Output
Surface chlorophyll-a on a 1/4° near-global grid. The seasonal experiment produces monthly forecasts to six months. A separate reconstruction experiment uses five-day averages.
Access type
Weights unverified
Availability
The paper offers software by request from the corresponding author. A public pretrained checkpoint or release was not verified.
License scope
The article is CC BY 4.0. Code/weights redistribution terms were not verified. The paper identifies the licenses/providers for source data separately.
Compute
Authors trained on one 40 GB A100 and report training in hours and six months of forecast maps in minutes on a single GPU, conditional on having the physical forecasts. This has not been replicated on the L40S.
Evaluation
Validate against GlobColour. The paper evaluated five-day reconstructions over 2018–2023 and monthly seasonal forecasts over 2020–2023, with BIO4 as a contextual comparison. For Pioneer, score surface chlorophyll against seasonal climatology; measure taxon concentrations separately using IFCB.
Notes
The authors used higher-resolution SEAS5 supplied by ECMWF. Public monthly SEAS5 inputs are 1° and require interpolation for the 1/4° workflow. Surface chlorophyll alone cannot identify plankton or recover a subsurface chlorophyll maximum.

Monthly 1/4° forecasts to six months. The full state comprises 29 biogeochemical variables plus temperature and salinity at 24 depths, including nutrients, oxygen, carbon pools and plankton variables.
Access type

Availability
Author preprint, Mercator project summary and EGU 2026 abstract are public. A public code or pretrained-weight release was not verified.
License scope
The preprint and EGU presentation document scientific work. Model code/weights reuse terms were not verified.
Compute
The authors describe a compressed, progressively coupled architecture. A comparable GPU runtime, peak memory or L40S benchmark was not verified. The earlier chlorophyll U-Net timing is a different experiment.
Evaluation
Tested against BIORYS4 for 2020–2022, with persistence and climatology baselines. Seasonal skill against a numerical analysis needs a separate test against measured nutrients, oxygen or chlorophyll at Pioneer, grouped by lead and depth.
Notes
Mercator reported a NeurIPS@Cam community poster award in December 2025 (https://www.mercator-ocean.eu/news-en/bg4sea-ai-forecasting/). There is an EGU 2026 contribution (https://meetingorganizer.copernicus.org/EGU26/EGU26-13007.html) and a July 2026 author preprint. A NeurIPS 2026 main-conference listing was not verified in the program (https://neurips.cc/Downloads/2026).

NASA SeaBASS validation matchups

Input
Atmosphere-corrected remote-sensing reflectance (sr⁻¹) at 443, 488 and 547 nm from the same water pixel.
Output
Estimated chlorophyll-a (mg/m³), selected blue band and blue-to-green ratio.
Access type
Published coefficients

Compute
Deterministic polynomial evaluated on the browser CPU; no GPU or network service required.
Evaluation

Notes
R2022 coefficients documented 6 November 2023, Table 1. The demonstration starts with illustrative reflectances. NASA’s blended chlor_a product also uses a color-index retrieval.
