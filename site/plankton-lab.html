Use the supervised ten-class model fitted to specialist-labeled WHOI crops. The classification head was trained on the OOI server’s NVIDIA L40S using frozen ImageNet features. Download your personal ONNX export from the notebook to run MobileNet on your own device.

Held-out WHOI images

How well did the pilot models do?

Both models trained on 1,280 images from 989 instrument bins. We held out 25 images from each of ten classes, drawn from 211 separate bins. A bin is one instrument acquisition.

Macro-F1 gives each category equal weight. The OOI NVIDIA L40S run and an independent CPU run produced the same MobileNet validation accuracy and macro-F1. Accuracy on Pioneer storm imagery still requires independent labels.
