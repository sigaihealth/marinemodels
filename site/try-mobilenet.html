    Interpreting this pilot

    This project trained a classification head on 1,280 labeled WHOI crops using frozen TorchVision MobileNetV3-Small image features. A reference CPU fit matched 221 of 250 held-out labels (88.4%), with macro-F1 of 0.884. Those scores describe the balanced ten-class WHOI subset. Accuracy on Pioneer samples requires independent expert labels.

    Preprocessing preserves the crop’s aspect ratio, resizes it with bilinear interpolation, pads to 224 × 224 using the median of the corners and applies ImageNet normalization.
