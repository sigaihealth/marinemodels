Source atlas

Datasets, models, benchmarks and data services for marine AI, gathered in a November 2026 survey. Each entry lists its licence, whether it needs an account, how to get it and whether its link answered when we last checked. The model workspace holds the smaller set we have tested in depth.

Link status comes from one automated request per source from a single network. “Account or access needed” means the server answered but asked for credentials; many of those sources are free once you sign up. “API endpoint” means the address accepts programmatic requests only. Licence groups are a quick reading of each source’s stated terms, so check the original terms before you rely on them. To suggest a source or a correction, contribute it.
