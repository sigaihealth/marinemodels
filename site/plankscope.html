Plankton lab / PlankScope comparison

Connect PlankScope

Bring predictions from your PlankScope instrument and match them with WHOI on the same original images. To classify a new crop, open the SIG.AI Plankton Classifier.

Leave the WHOI field empty to use the 24 published Pioneer predictions. Both files must cover the same image checksums. Files are read in your browser.

From instrument to review

The camera pipeline detects objects before classifying crops. For the Pioneer comparison, the 101-category SIG.AI Plankton Classifier received the same crops as WHOI. Both produced predictions for all 24 images. Their label vocabularies differ. A blind review will establish which groups can be compared and how often each model is correct.

Authorized instrument workspaces can also run a paired comparison in Jupyter. In the identification notebook, choose the paired WHOI and PlankScope comparison to run both on one image. This page also compares existing CSV exports on your device.

Required CSV fields

PlankScope needs image_sha256, label and confidence. WHOI needs roi_sha256, roi_id, label_1 and softmax_1. Each image must occur once per file with a score between 0 and 1. Use the offline comparison tool for large batches or a reviewed class mapping.
