Connect PlankScope

Bring predictions from your PlankScope instrument or standalone crop classifier. Match them to WHOI predictions on the same original images and inspect the two suggestions side by side.

Leave the WHOI field empty to use the 24 published Pioneer predictions. Both files must cover the same image checksums. Files are read in your browser.

From instrument to review

The camera pipeline detects objects before classifying crops. For the Pioneer test, the standalone 101-class ResNet-50 received the same pre-cropped images as WHOI. Both produced predictions for all 24 images. Their label vocabularies differ. A blind review will establish which groups can be compared and how often each model is correct.

PlankScope owners run the classifier in their own environment. This connector uses exported results. A future instrument adapter could submit approved sample manifests and selected results to a shared workspace.

Required CSV fields

PlankScope needs image_sha256, label and confidence. WHOI needs roi_sha256, roi_id, label_1 and softmax_1. Each image must occur once per file with a score between 0 and 1. Use the offline comparison tool for large batches or a reviewed class mapping.
