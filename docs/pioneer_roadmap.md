# Pioneer plankton classification and storm forecasting roadmap

The first scientific result will estimate how much of the February 1 increase in image regions per milliliter came from diatoms, other plankton, detritus, and unresolved material. The six-day Winter Storm Gianna archive contains 123,609 regions from 42 moored water samples at 7 m. A frozen WHOI classifier has produced provisional predictions for 24 gallery crops. The 35B language model and the full-archive classifier run are proposed experiments. [Pilot and data inventory](pioneer_plankton_models.md) · [OOI storm observations](https://oceanobservatories.org/2026/09/ooi-plankton-imagery-and-co-located-environmental-data-now-ready-for-analysis/)

## Validate recognition before interpreting composition

Randomly select ten distinct ROIs per bin, **420 unique images** in total. Record the random seed and each bin’s inclusion probability. Have a second reviewer independently reread two of the ten per bin (**84 additional reviews**). Record disagreements, resolve them with both readers, and retain an unresolved group. Reserve whole sampling dates for final evaluation before adjusting mappings, thresholds or classifier weights. Collect additional ambiguous and rare examples separately for training. [WHOI classifier and class list](https://huggingface.co/sosiklab/NES-plankton-IFCB-classifier-2022) · [WHOI labeled reference set](https://huggingface.co/datasets/sosiklab/NES-plankton-IFCB-classifier-2022-dataset)

For each bin, divide each predicted group’s count by the analyzed volume. A chain is one ROI until a cell-counting model is validated. Compare predicted fractions against the blind audit, using the bin’s total ROIs to expand the audited fraction to an estimated count. Sum counts and volumes before calculating a pooled concentration. Report broad-group precision, recall, abstention, and absolute error in ROIs/mL. Quantify sampling uncertainty within bins and account for repeated observations across time when comparing phases. Ten audited ROIs per bin provide a coarse estimate. Expand the audit or combine categories when intervals are too wide to resolve a change. [Estimating abundance under classifier error](https://doi.org/10.1002/lom3.10399)

## Use the L40S for scientific reporting

Start with **Qwen3.5-35B-A3B-GPTQ-Int4**, an Apache-2.0 vision-language model with 35B total parameters and roughly 3B active per token. Its published weights total 22.74 GiB. The L40S snapshot showed 46,068 MiB total and 45,458 MiB free. Runtime allocations, image processing and the inference cache also consume GPU memory. The vLLM recipe lists a single 24 GB GPU for this checkpoint. Verify the local engine with one request at a time, initially capped at 4,096 tokens including output. Try text first, then two reviewed crops, then 8,192 tokens. Record peak VRAM, latency, throughput, and successful completion. Schedule the LLM and image classifier in separate GPU sessions. [Pinned Qwen weights](https://huggingface.co/Qwen/Qwen3.5-35B-A3B-GPTQ-Int4/tree/3af5ca2972faf6de1fd6f4efc4d8d319ca751e8b) · [vLLM serving recipe](https://recipes.vllm.ai/Qwen/Qwen3.5-35B-A3B) · [NVIDIA L40S](https://www.nvidia.com/en-us/data-center/l40s/)

Compare **35B Qwen, Qwen3-8B and an OpenAI API model** on identical text evidence. Record model versions, generation limits, latency and API cost. For a separate image experiment, compare vision-capable models using identical crops. Build an initial set of 30 questions covering numbers and units, group identification, competing storm explanations, and unanswerable cases. Grade numerical agreement with code, whether citations support claims, and whether the report acknowledges missing evidence. Require correct sample IDs and units and zero unsupported species or causal claims on the release set. Code supplies the measurements and quality flags. OOI, WHOI, WoRMS and primary studies supply background. [Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B) · [OpenAI structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs) · [WoRMS taxonomic references](https://www.marinespecies.org/aphia.php?p=webservice)

**Fine-tuning decision.** If expert corrections expose a recurring error that retrieval and prompting fail to fix, train an initial QLoRA adapter on an unmodified Qwen3-8B checkpoint loaded in NF4. Keep expert-reviewed training reports separate from held-out events and questions. Test a short sequence at microbatch one through a full optimizer step and record peak memory. Compare the adapter against its untuned base and the frozen 35B model. Consider a larger adapter only if the held-out improvement and memory measurements justify it. For image-recognition errors, adapt the vision classifier on separate Pioneer labels. [PEFT quantization and adapter training](https://huggingface.co/docs/peft/developer_guides/quantization)
